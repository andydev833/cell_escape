# CELL / ESCAPE — MVPのUI / UX

## 今回の仕様

一画面ずつ攻略する、キーボードを使った脱出ゲーム。第1〜50室を実装（設計は docs/Excel_Escape_Stages_01-50_Master_Design.md、第2〜5室の詳細は docs/Excel_Escape_Stages_02-05_Design.md）。

表計算風の暗い部屋、白い小さなキャラクター、遠くに光る扉。ゲーム中にもクリア後にも学習・Excel・時短などの説明を表示しない。ヒントは右上の「？」を自分で押したときだけ出す。

## 見た目

- 黒緑の背景、淡い黄緑のアクセント、クリーム色のキャラクター。
- 部屋はワークシート風の罫線、行番号、列記号、名前欄を持つ。
- 上部に部屋番号と短い題名、右上に設定。ゲーム内右上に「？」。
- 下部に移動・再挑戦のキーと死亡回数。カウントダウンなし。
- モーダルはヒント・設定だけ。ゲームの開始・失敗・クリアは盤面上で表示。

## ゲームの流れ

開始「出口へ。」→右へ3歩は安全に歩ける→4歩目のF5で天井のプレスに潰される→すぐにEnterまたはRで再挑戦→Ctrl＋右で出口へ→「抜け出した。」

学習の振り返りや操作の解説を挟まない。「？」は気づき、方向性、具体的なキーの三段階で表示する。

## 部屋の実データと罠（v0.4）

- 主人公はB5、出口はL5。B5:L5は連続した値を持つ。
- ステージ定義（engine.jsの`ROOM`）に通路`walkable`(B5:L5)、安全区間`safe`(B5:E5)、罠区間`traps`(F5:K5, `ceilingPress`)を明示し、判定と描画の両方がこれを参照する。
- F5:K5に着地すると天井のプレスが落ちる。判定は着地セルだけで、Ctrl＋右でL5へ跳ぶ途中のセルは発火しない。B5:E5のどこからでもCtrl＋右で脱出できる。
- 通路の外（上下、B5より左、部屋外へのCtrl移動）は壁。位置も死亡回数も変えず、キャラの小さな押し返しと、押した側の短い線だけで示す。
- 罠と部屋はゲーム独自の表現。移動先を計算するエンジンとゲームの罠を分ける。
- クリア後は盤面入力を止める。再挑戦で同じ部屋を遊び直せる。

## 罠の演出（落下プレス）

- 発動前は罠セルの天井プレートと短いガイドレール、床のスイッチの継ぎ目だけが見える。安全床には継ぎ目を描かない。
- 着地後の時間軸：0ms スイッチが沈みキャラが「！」で驚く → 60–180ms プレスが落下 → 180ms 衝突、キャラが縦に潰れる、盤面だけ約3px・130msの揺れ、薄い赤橙の衝撃1回、金属音＋低音 → 240ms キャラが6個の破片に弾けて消える → 480ms 盤面下部に小さな「やられた。」と「もう一度」。
- 発動後のプレスは下りたまま残る。死亡回数は衝突の瞬間に表示へ反映する（判定上は着地時に確定）。
- 一度見たプレスだけ、再挑戦後に天井プレートと床に小さな傷が残る。再読み込みで消える。
- 動きを控えめにする設定：揺れ・衝撃色・破片なし。プレスは上→下の切り替えで示し、キャラは潰れた後に消える。
- 演出の時間はゲーム内の時計で進み、ヒント・設定を開いている間とタブ非表示中は止まる。再挑戦・開始で予約済みの演出を試行IDごと無効化する。

## 操作と復帰

- 移動は物理キーボード。盤面クリックで出口へ飛べない。
- 長押しの自動リピートを無視して、試行ごとの入力を明確にする。
- 死亡中に押し続けていたキーを、再挑戦後の一歩として扱わない。
- ヒント・設定中は盤面が入力を受け付けない。
- タブやウィンドウから戻ったら、クリックで操作を再開できる。
- TabでUIへ移動した場合も、そのフォーカスのまま盤面を動かさない。
- MacではOSのCtrl＋矢印との衝突を避けるため、⌘＋矢印でもプレイできる。実際のOSによるキー取得には実機確認が必要。

## 設定

効果音、動きを控えめにする設定を用意。設定のみブラウザー内に保存する。音は初期オフ。ヒントに利用制限・減点なし。

## 実装

ビルド不要のHTML/CSS/JavaScript。描画はCanvas。ルールは独立したengine.jsに分離し、ステージの連続データ、移動先、罠、死亡・クリアの状態を検証する。外部画像・外部ライブラリ・ログイン・課金・サーバーデータ保存なし。

## 第2〜5室（実装）

- ステージは `dist/stages.js` にデータだけで定義し、`engine.js` が A1 表記をコンパイルする。床（`floor`）とセルの値（`values`）は別データ。石・鍵は `{token}` で値と区別する。
- 第2室：B3:L3 上段、E3:E7 枝道、E7:L7 下段。L3 は偽出口（床が開き歯車へ落ちる、扉の光が消える）、E5:E6 は崩れる床、F3:K3・I7:K7 はプレス。E3 から下へ伸びるレールが手掛かり。
- 第3室：F5:J5 の感圧板と5つのランプ。Shift(+Ctrl)+矢印で選択範囲を広げ、主人公（アクティブセル）は動かない。5枚が同じ選択に入ると解除を保持し扉が開く。未解除で単独着地すると針。
- 第4室：C5 の石を Ctrl+C／Ctrl+V で H5 にも置くと扉上の2灯が点き扉が開く。条件未達で L5 へ入るとシャッターが落ちる。切り取りで移すと C5 が空になり未達。
- 第5室：鍵は1本だけ。コピーで2本になると、監視装置が2本を赤く結んで約0.45秒見せてからレーザー。Ctrl+X／Ctrl+V は元と先を同時に更新し、扉が開く。Esc でコピー／切り取りを取り消す。
- 進行：クリア画面の「次の部屋へ」（Enter）で次室へ。下部のシートタブで開放済みの部屋へ移れる。進行は `cell-escape.progress` に保存。`?room=N` で任意の部屋を直接開ける（確認用）。
- Mac では ⌘ を Ctrl の代わりに受け付ける。⌘押下中は他キーの keyup が来ないため、⌘を離した時点で押下状態を解放する。

## 第6〜30室（実装）

- 部屋はすべて `dist/stages.js` のデータ。出口・罠・ルール・ラッチ・ランプは同じ条件式（`equals` / `token` / `fill` / `bold` / `numFmt` / `formulas` / `filter` / `latch` / `all` / `not` など）で書く。
- エンジン（`dist/engine.js`）が持つExcelの意味：確認パネル（OK／キャンセル）、セル編集（F2で中身を保持、文字入力で置換、Enterで確定して下へ、Ctrl+Enterで選択範囲へ一括、Alt+Enterでセル内改行、F4で参照の固定）、Undo（値と書式だけ。歩行・死亡・ラッチは戻さない）、Delete（内容だけ消す）、列・行・現在領域の選択（全列・全行は範囲として持つ）、Ctrl+D／Ctrl+R、検索（部分一致）、置換（範囲選択があればその中だけ）、ジャンプ、Ctrl+Home／Ctrl+End（使用範囲の右下）、フィルター（行を隠すだけで消さない）、値だけ貼り付け（貼り付け先の書式を保つ）、数値書式・太字、旧来のメモ、数式（数値・参照・四則演算の小さなモデル）、新規シート。
- ゲーム内パネル（検索・置換・ジャンプ・フィルター・形式を選択して貼り付け・メモ・確認）は盤面の上に小さく出し、キャラから遠い側に置く。Enterで実行、Escで閉じる。
- 値を変えた操作で罠が作動したときは、原因（赤い印、二本の鍵を結ぶ線など）を約0.26〜0.45秒見せてから作動する。
- キー：文字キーは `e.code` で読む（⌥やキー配列の影響を受けない）。Ctrl+R はフィル（再挑戦は修飾キーなしのR）。Mac では ⌘ を Ctrl の代わりに受け付け、⌘Space／⌘H が OS に取られる第12・19室はヒントを ⌃ 表示にする。
- `?debug` を付けると `window.__game.state` で状態を見られる（確認用）。
- 未確認：Mac実機での ⌃Space・⌃H・fn+⌘←（Home）・Shift+F11（F11がOSに取られる設定）、Windows版ブラウザーでの Ctrl+Shift+1 と各Ctrl系の既定動作の抑止。

## 第31〜50室（実装）

- 追加したExcelの意味：Redo（Ctrl+Y／Ctrl+Shift+Z。歩行や選択では消えず、新しい編集で消える）、複数範囲の選択（F8＝拡張、Shift+F8＝追加。ステータスに EXTEND／ADD TO SELECTION）、Ctrl+Shift+Home／End、保護シートのTab移動とShift+Enter／Tabでの確定、セルの挿入・削除（右／下、左／上。行・列全体なら行・列ごと）、オートSUM（Alt+=）とSUM関数、数式表示（Ctrl+`）、今日の日付（Ctrl+;。日付は数値＋日付書式）、複数シートのブック（シートごとにセル・位置・履歴を保持）、フラッシュフィル（区切り文字の前後を例から学ぶ）、テーブル（範囲と見出し）、手動計算とF9、埋め込みグラフ（Alt+F1）とグラフシート（F11）、行・列の非表示と再表示、Shift+F10 のメニュー、斜体・下線・取り消し線、形式を選択して貼り付け（数式F・書式T・列幅W）、列幅、保存と名前を付けて保存（ブックごとのスナップショット）。
- 試遊の指摘を最初から反映：パネルはキーボード操作のみ、目指す形を盤面に出す（札・型・ランプ）、不要な偽ゴールは置かない（34室のK4、40室のArchive、45室のF6、50室のGate!L5は罠にしていない）、ショートカットを迂回できる移動は塞ぐ（31・32・34室は Ctrl+G 不可、35・36室は入力と貼り付けを封印）。
- ブラウザーが取るキーの代わり（いずれもExcelに実在する操作）：Ctrl+PageUp/PageDown → ⌥/Alt+←/→（Mac版Excel）、Ctrl+T → Ctrl+L、Ctrl+5 → ⌘+Shift+X（Mac版Excel）、F12 → Ctrl/⌘+Shift+S（Mac版Excel）、F11・Alt+F1・非表示/再表示 → Shift+F10 のメニュー。
- 未確認：Windows版Chromeで Ctrl+PageDown・Ctrl+T・Ctrl+5・Ctrl+9 は届かない（または届くかが未検証）。Mac実機での F8・F9・F11・F12・Shift+F10（fn併用）、JIS配列の Ctrl+` と Ctrl+;。49・50室の途中再開（チェックポイント）と保存庫の再読み込み後の復元は未実装。
